**Xwalk** resolves any protein identifier to one pinned, quality-tiered structure with a stable ID. Give it a gene name, UniProt accession, PDB entry or chain, AlphaFold ID, or raw sequence, and get back a structure with cross-references to AlphaFold DB, PDB, UniProt/UniParc and ESM Atlas, plus full provenance.

It is built agent-first: a hosted MCP server and agent skills, with a REST API underneath.
